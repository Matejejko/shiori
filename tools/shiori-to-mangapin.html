Shiori → MangaPin

Turns a Shiori backup (Shiori-DDMMYYYY.json) or a server snapshot into a file MangaPin can import. Everything happens in this page: your library is not uploaded anywhere. You can also save this file and open it offline.

Kept: series, reading progress, folders, tags, covers and every other MangaPin field. Not kept (MangaPin has no place for it): Shiori's sync data (edit times, deleted series) and your folder/tag names. A server snapshot has no covers inside; use a backup for those.

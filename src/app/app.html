OpenCloud / WebDAV

Create an app token in OpenCloud (Settings → App Tokens, or opencloud auth-app create). It is stored only in this browser, never synced. Library lives in /Shiori/ on the server.

Site access

This browser has not granted Shiori access to websites yet (Firefox asks separately). Without it, release checks, covers and sync cannot reach their servers.

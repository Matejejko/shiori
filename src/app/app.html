Import

You get a dry-run summary first; nothing changes until you confirm.

Export

Writes Shiori-DDMMYYYY.json: a Shiori backup of your whole library with covers. Import it here on any device. Going back to MangaPin? Open tools/shiori-to-mangapin.html from the Shiori repository and drop the backup on it.

OpenCloud / WebDAV

Create an app token in OpenCloud (Settings → App Tokens, or opencloud auth-app create). It is stored only in this browser, never synced. Library lives in /Shiori/ on the server.

Site access

This browser has not granted Shiori access to websites yet (Firefox asks separately). Without it, release checks, covers and sync cannot reach their servers.

Status

Folders are numbered; name them here (names sync between your devices). Tags need no setup: they are the genre names the sites use.
